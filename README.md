# متجر د. محمد النبهاني — منتجات فوريفر ليفينج

متجر إلكتروني متكامل بالعربية (RTL) لإدارة وبيع منتجات فوريفر ليفينج، مبني على **React + Express + SQLite (Drizzle ORM)**، مع سلة مشتريات، مفضلة، إتمام طلب عبر واتساب، ولوحة تحكم كاملة.

- **6 فئات**: عصير الصبار، المكملات، العناية بالشعر والبشرة، العناية الشخصية، التخسيس ونزول الوزن، المجموعات.

## المزايا

- واجهة عربية RTL كاملة مع وضع ليلي، بحث، فلترة حسب الفئة، وترتيب حسب السعر.
- صفحات: الرئيسية، المتجر، تفاصيل المنتج، السلة، إتمام الطلب، المفضلة، لوحة التحكم.
- **الأسعار تُحسب على الخادم دائمًا** — لا يمكن التلاعب بالأسعار من المتصفح.
- إتمام الطلب: يُحفظ الطلب في قاعدة البيانات ثم يُرسل عبر واتساب برسالة جاهزة تتضمن رقم الطلب والتفاصيل والإجماليات.
- لوحة تحكم محمية: إحصائيات، إدارة الطلبات وتحديث حالتها، إضافة/تعديل/حذف المنتجات، وتعديل إعدادات المتجر (الواتساب، السبونسر، الشحن، الألوان، نصوص الترويج).

## التشغيل محليًا

```bash
# 1. تثبيت الاعتماديات
npm ci --prefer-offline

# 2. إنشاء جداول قاعدة البيانات
npm run db:push

# 3. استيراد المنتجات والإعدادات (من data/products.json)
npx tsx script/seed.ts

# 4. توليد صور المنتجات (اختياري — موجودة مسبقًا في client/public/products)
node script/generate-images.mjs

# 5. تشغيل خادم التطوير
npm run dev
```

ثم افتح `http://localhost:5000`.

## البناء للإنتاج

```bash
npm run build
NODE_ENV=production node dist/index.cjs
```

## لوحة التحكم

- الرابط: `/admin` (من القائمة العلوية)
- كلمة المرور الافتراضية: `bizmind2026` — **غيّرها فورًا** عبر ملف `.env`:

```env
ADMIN_PASSWORD=كلمة-مرور-قوية
ADMIN_SECRET=سلسلة-عشوائية-طويلة
```

## استبدال صور المنتجات

صور المنتجات الحالية SVG بهوية المتجر (نبتة صبار + كود SKU + الاسم). لاستبدالها بالصور الرسمية: ضع الصور في `client/public/products/` بنفس اسم الكود (مثال: `815.webp`) ثم حدّث حقل `image` للمنتج من لوحة التحكم.

## بنية المشروع

```
├── client/               واجهة المستخدم (React + Tailwind + shadcn)
│   ├── public/products/  صور المنتجات (31 SVG)
│   └── src/pages/        الصفحات: الرئيسية، المتجر، المنتج، السلة، إتمام الطلب، المفضلة، لوحة التحكم
├── server/               الواجهة الخلفية (Express + Drizzle)
├── shared/schema.ts      مخطط قاعدة البيانات
├── data/products.json    بيانات المنتجات المستخرجة من الملف الأصلي (31 منتجًا)
├── script/seed.ts        سكربت الاستيراد
├── source/original.html  الملف الأصلي كما هو (مرجع محفوظ)
└── data.db               قاعدة بيانات SQLite
```
